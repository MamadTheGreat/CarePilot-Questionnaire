# وب‌سایت پرسشنامه‌های پژوهشی

این نسخه یک نمونه اولیه قابل‌اجرا برای سه گروه پرسشنامه فعال است:

- بیماران
- همراه بیمار
- کارکنان درمانی

## اجرا

از پوشه `survey_app` اجرا کنید:

```powershell
node server.js
```

صفحه انتخاب پرسشنامه:

```text
http://127.0.0.1:4173/
```

داشبورد ارزیابی:

```text
http://127.0.0.1:4173/admin.html?key=local-review
```

کلید داشبورد را با متغیر محیطی `SURVEY_ADMIN_KEY` تغییر دهید.

## ذخیره داده

پاسخ‌ها در اجرای محلی در `data/responses.ndjson` ذخیره می‌شوند. در اجرای عمومی، اگر متغیر `GOOGLE_APPS_SCRIPT_URL` تنظیم شده باشد، هر پاسخ ابتدا به Google Apps Script ارسال و در Google Sheet ثبت می‌شود و سپس یک نسخه پشتیبان محلی نیز نگهداری می‌شود.

کد آماده Apps Script در مسیر `google-apps-script/Code.gs` قرار دارد. مقدار `SPREADSHEET_ID` در آن با شناسه Google Sheet پروژه تنظیم شده است.

داشبورد دو نمای اصلی دارد:

1. آمار تجمیعی هر سؤال و گزینه
2. پاسخ‌های فردی هر شرکت‌کننده

خروجی CSV از مسیر زیر در دسترس است:

```text
http://127.0.0.1:4173/api/admin/export.csv?key=local-review
```

برای استقرار روی Render، متغیرهای محیطی `SURVEY_ADMIN_KEY` و `GOOGLE_APPS_SCRIPT_URL` را تنظیم کنید. فایل `render.yaml` تنظیمات سرویس را آماده کرده است.

این نسخه برای پایلوت و جمع‌آوری اولیه مناسب است. پیش از استفاده عمومی، باید HTTPS، احراز هویت مدیر، پشتیبان‌گیری، سیاست نگهداری داده و بررسی اخلاقی/حقوقی اضافه یا تأیید شوند.
